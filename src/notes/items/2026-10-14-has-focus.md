---
title: "Outline the card, not the link inside it"
topic: css
---
When a whole card is clickable through one link, the focus ring should go around the card. `:has()` lets the card react to what is happening inside it.

```css
.tile a:focus-visible { outline: none; }

.tile:has(a:focus-visible) {
  outline: 2px solid #5dd8ff;
  outline-offset: 3px;
}
```

Only remove the link's own outline if you are sure the card gets one in its place. A page with no visible focus is much worse than one with a slightly small ring.
